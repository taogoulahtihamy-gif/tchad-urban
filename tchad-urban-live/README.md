# Tchad Urban — Phase 1 régénérée

Cette version intègre les corrections demandées :

- hero conservé dans l'esprit de la première version ;
- vraies pages autonomes : Accueil, Le Mur, Services, À propos, Contact, Commander ;
- suppression des numéros avant les titres de section ;
- bandeau Actualités corrigé sur une seule ligne, sans chevauchement ;
- textes réduits et hiérarchie plus équilibrée ;
- responsive desktop, tablette et mobile ;
- utilisation des véritables créations Tchad Urban.

## Lancer le projet

```bash
npm install
npm run dev
```

Ouvrir : http://localhost:3000

## Vérification production

```bash
npm run build
npm start
```
